# UX guidelines

## Homepage
- Show two main paths: customer / craftsman.
- Explain the process in four or five steps.
- Make trust and verified work visible immediately.

## Search page
- Keep filters simple at first: profession, location, specialization.
- Use cards with rating, verified jobs, distance, trust facts and shortlist CTA.
- Explain "why this craftsman fits".

## Public profile
- Hero with trust summary.
- Portfolio as image-first gallery.
- Reviews and expertise clearly separated.
- Distinguish platform-verified work from self-declared work.

## Job dashboard
- Make "what needs to happen now" the primary card.
- Use tabs for complexity.
- Use a readable progress tracker.

## Form design
- Split long forms into steps.
- Show autosave and progress.
- Use clear validation and helper text.
